# 固定因子与滚动权重的两轮比较

使用 V9 同一批预测、哈希校验的市场数据和 V11 保留持仓规则。代码 7a77ae5 固定三项试验，开发集选择记录 5ec29ad。低波动按过去 60 日收盘收益标准差升序排名，反转按过去 5 日收益升序排名，下一交易日执行。基础预测占单项组合的 75%，双项组合的 50%。新增变量均由价格计算。第二轮代码 39d33de 在已知历史上的独立后续试验中，用月度 Ridge 学习三个排名的权重，逐月仅纳入退出日期早于拟合日的标签。两个时期单独启动，至少 60 日预热，最多使用 252 日，正则系数 0.01。预热期采用 V11。

开发期 2020–2021，评估期 2022–2024，单边 20bp，同频等权对照评估期夏普 −0.026、累计 −5.45%。第一轮预设开发期信号门槛后按净夏普选择，选中 V11。低波动在评估期的 Rank IC 区块区间为 [0.0222, 0.0918]，六个半年折中五个超过 0.02。它相对 V11 的日均净收益差区间为 [−0.06, +3.53] bp，区块 20 日、1000 次、种子 17，未经多重比较校正。低波动风格的市场表现可能解释收益差异，现有实验未做行业或风格中性归因。固定 58 股的幸存者偏差和多次使用评估期限制了结论的外推。所有方案均未满足净夏普 >1，模拟盘未启动。
