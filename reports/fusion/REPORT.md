# 30/40/30异构数据框架：实现与实测接入

配置：`configs/fusion.json`。30%基本面、40%短周期价量、30%另类，解释为训练期校准后的预测信号权重。不是字段数或仓位比例。框架采集源提交：`0f56b1fd47697d306f6960091524e254b9ce9879`。

## 实际完成

| 部分 | 当前证据 | 状态 |
|---|---|---|
| 基本面30% | AKShare固定60只股票、6类指标；60只都能构建当前时刻的完整六指标向量 | 数据接通；组模型/历史OOF校准尚未完成 |
| 价量40% | 复用V4的27因子、12个滚动窗口、Ridge/ElasticNet/LightGBM输出契约 | 历史研究管道已通；不是新上线的实时预测 |
| 新闻 | AKShare真实采集10条，词典情绪代理，保留首次观察 | 前向样本；不是历史情绪档案 |
| Polymarket | 只读API实际获取10个市场、20条结果隐含概率观测 | 尚无经核验的证券/行业事件映射 |
| 卫星 | 公开STAC实际返回2个场景目录 | 未处理像素；不能当作经济活动因子 |
| X | 授权导出与实体映射导入接口 | 数据访问未配置，未做付费请求 |

当前快照共**34,858条数值观测**（包含同一公司的多个历史报表期），不是34,858条独立实时信号。来源网络失败0。采集在2026-11-10进行；旧报表的当前版本不等于其旧日首次发布版本，不能用本轮first_seen回填过去。

基本面字段为ROE、营收同比、利润同比、资产负债率、EPS、每股净资产。公司/报表期/单位保留；银行与一般行业、YTD与单季不可直接混用为同一因子含义，仍需行业处理与分组验证。

## 框架保证

- 观察时间、发布时间、首次观察时间三者最大值决定可得性；公告日期不精确到时刻时保守记日终，更新/修订不能提前进入旧决策。
- EntityLink要求有证据和生效/首次观察时间；不把Polymarket全球事件或卫星示例坐标默认映射给每只股票。
- 缺组或缺配置的另类子来源时score=null、status=blocked，权重不变。默认新闻/X/Polymarket/卫星各占另类组25%，未接通者不能靠其余来源代填。
- 组模型校验训练标签和特征时间，模型状态含数据与标签哈希；只在过去OOF分数上校准组尺度，固定裁剪后保留逐组贡献。
- 当前数据采集、字段向量、模型接口、融合与拦截可测试。合成测试夹具只验证正确性，不计算金融业绩。

## 当前结论

**融合尚不能作为策略运行，未生成新的IC/IR/夏普，模拟盘未启动，订单0。** 除了缺X与卫星经济特征、事件映射及历史首次可见档案，也缺三组共同可用的OOF预测/校准集合。

V4全价量研究结果仍保留：Ridge/ElasticNet均值RankIC约0.037，但稳定性不足，主成本筛查净夏普约0.12/0.13，未达到>1。不能把新增数据源数量当作已解决此问题的证据。

## 下一步可执行实验

冻结统一股票池/日期/成本，比较价量、价量+基本面、价量+另类、完整30/40/30，报告同日配对ΔIC/ICIR、覆盖率和成本后收益。缺组实验必须用单独配置，不在完整实验内动态改权重。没有可核验的旧档案时从新的共同可得时刻前向积累，不虚构长回测。
