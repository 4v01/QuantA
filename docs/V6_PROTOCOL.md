# V6冻结协议：开源历史新闻替代与首轮融合IC

本轮不覆盖V5的严格first_seen规则。新增**回顾性、按供应商公告/更新日期重建**研究配置configs/v6.json。对当前财务快照、历史新闻文件无法证明完整原始可得性，strict_pit=false、模拟准入false，不因IC好坏改变。

## 数据先于模型确定

CMIN-CN来自ACL2023作者仓库BigRoddy/CMIN-Dataset，固定提交3f571a53b81d8f3ea7b3afb9877bdbdbeae54c97。仅读原始无表头XLSX的日期、标题和来源，保留首行、按股票/日期/标题去重；不读其股票涨跌标签、预处理收益或模型预测。与原60股票池按财务代码/名称、新闻文件名、原始价格代码三项核对得到58只；600703和600745缺清晰新闻映射，不补股。433,482条标题，保存逐文件及清洗缓存SHA256。

CMIN只有2018–2021历史，因此本轮不把2022–2026缺档当成“没有新闻”。所有模型统一使用同一58股、相同日期与可得字段行；不将不同股票池/年份的指标直接比较为提升。

基本面沿用不可变AKShare快照六类字段，但有效研究日期为max(NOTICE_DATE, UPDATE_DATE)的次日，不把后修订值按旧公告日提前用。按最新可得报告期、最大550日龄取值，至少3/6字段可得才保留行。其余缺字段仅训练中位数插补并增加缺失标记；不是把整组缺失填0。此规则仍不能认证未知历史修订链。

新闻只有日期，次日才进入特征；周末消息在后续交易日可见。按1/5/20日历天构建条数、简明词典的正/负/净词计数、标题长度，共15项。没有条目表示本有限档案中未检索到，不代表整个市场没有新闻。词典不是训练标签或人类情绪真值。

价量复用V4的27项与冻结行情版本，不读取CMIN价格当因子或标签。H=5：t收盘决策、t+1开盘到t+6开盘供应商后复权收益代理。标签不是已认证现金分红总回报，价格历史版本也未PIT认证。

## 首轮试验

2020年两个半年折为首轮诊断；每折此前18个月训练、6个月验证。训练标签退出日必须早于验证开始，最终重拟合标签早于测试开始。2020年底退出到2021的标签不用于首轮IC，避免优化时提前看随访结果。

基本面、价量、新闻分别使用Ridge，alpha=[1,100,10000]；仅按验证日均|RankIC|选参数/方向。每组预测先在同日截面转秩，再由过去验证预测均值/标准差校准，固定裁剪±3，组合0.3F+0.4P+0.3A。验证本身使用更早训练的模型，不用全样本分数校准。融合不按样本外IC翻转方向或选权重。

主要结果为有向平均RankIC、日ICIR、20日区块1000次95%区间，价量基线为共同日期配对ΔIC。公开全部组结果与预测相关性，不只报告融合赢家。预算每折3组×3alpha及最终重拟合，seed17。

## 自主优化与随访

读完2020首轮IC再提出**一个**有证据的改进，记录原因、配置/源提交与选择时刻；冻结并推送后再运行2021两半年折，基线和优化方案同时比较。2021价格已在V4出现过，所以只是后续回顾性复核，不能称为绝对未见或前瞻确认。不按2021表现再换方向，不删除失败改善。

## 收益筛查和边界

同一连续OOF日历、5日调仓、前20%等权、只多无杠杆，10/20/30bp每边成本，20bp主场景；末尾清仓计费。年度不重置。公开价格单组、基本面、新闻、融合与全池等权。分数份额/后复权筛查不能替代整手、最低费率、公司行动、停牌/涨跌停竞价的可执行账本，不据此进入模拟盘。

所有正式拟合要求clean源提交，记录配置、行情/新闻/财务指纹、环境、参数、方向、校准、模型、预测和种子。第一次结果保留；来源无完整档案的事实不会因找到开源代码而消失。
