# V7预先固定协议：稳定性、可靠性、目标匹配与Kaggle迁移

2026-11-16（北京时间）。旧V1–V6文件保留。本轮不承诺一定达到IC或夏普；目标仍是稳定有向RankIC≥0.02、净夏普>1。

## 阶段和数据

2020–2021为已知开发资料。开发完成后按预定平均IC/覆盖率选择一个候选，将候选、配置和开发证据公开封存，再计算2022–2024后续融合指标。2022–2024市场价格曾用于V4，所有资料都在2026年取得；故后续检查是回顾性的、本轮方法选择不使用其融合结果，不能称为全新市场盲测或前瞻确认。

股票池固定原CMIN交集58股。2018–2021用不变CMIN原始标题；2022–2024用FinMultiTime作者公开数据，固定HuggingFace版本72d4e97b9acb92651949b8efb22c55676ff633ff，仅提取datetime和非空title，丢弃重复标题，禁止使用生成式summary及任何目标/收益字段。后段43,231条去重标题。字段缺失意味着有限档案中无可用标题，不宣称全市场没有新闻。跨来源分布变化是重要限制；所有方法在后段使用同一份资料。

新闻次日可用。财务仍为max公告/更新日次日重建；原始版本、未知修订、存续股票池未认证。因此strict_pit=false，不能自动入模拟盘。原V5全来源严格缺失规则不变，另类组在本研究内仍明确为历史新闻。

## 统一切分与标签

每半年测试，前6个月验证；旧式/前两种改善臂训练18个月，长历史及以后30个月，最早2018-01-01。参数仅用过去验证选择。**所有方法训练和验证统一按H20退出日purge**，并保持完全相同的测试行，避免多期限模型提前看到标签；主要IC始终是原H5（收盘t→t+1开盘建仓、t+6开盘退出）的供应商后复权收益代理。开发末尾跨到2022的标签不计开发IC。

## 七个有限预算对照

| 方法 | 相对前一步 |
|---|---|
| legacy_matched | V6式绝对验证IC选参/定向，18月训练；本轮共同H20 purge，故不可将其数值直接当原V6复刻 |
| signed_stable | 不再翻向；把过去验证日期分4块，按mean(IC)-0.5*std(四块均值)选Ridge alpha |
| reliable | 在前项基础上，按过去验证均值/波动/正块比例缩小弱组分数 |
| long_history | 训练最长30个月，缓解单段历史过窄；其它规则相同 |
| aligned_fund | 基本面ROE/EPS按已知报告季度做YTD近似年化、加入63交易日变化和报告日龄，基本面训练目标H20；其它组仍H5；评价仍H5 |
| kaggle_context | 在前项基础上增加同日已知市场收益/波动与相对特征交互，Ridge |
| kaggle_rank | 相同上下文，价量分支换为小型LightGBM LambdaRank；基本面/新闻仍线性 |

这是依次添加模块的流程对照；signed_stable同时改变方向与选参准则，不把它声称为单个组件的纯因果效应。Ridge alpha仅[1,100,10000]。Ranker固定7叶/深3、min_child200、L2=20、lr=.03、最多300轮、过去验证NDCG@10早停30轮。没有随机行切分、没有比赛式排行榜选模。seed17、CPU两线程。

## 校准、缺失与权重

每组预测按同日截面转秩，用更早验证预测尺度校准，裁剪±3。名义权重始终30%基本面/40%价量/30%新闻，不重新分配。

可靠性系数为max(验证IC均值,0)/(max(均值,0)+四块均值标准差+0.02)×正均值块比例，范围[0,1]。它是明确的启发式收缩，不是概率或显著性证明。实际有效贡献随系数改变，逐组全部公开；不能把“名义30%”说成实际持仓或收益贡献30%。数据缺失仍不能靠重分配补齐；已拟合组预测零α与原始资料缺失是不同状态。

常数融合分数的IC未定义，报告IC覆盖率；选模另用零信用的coverage-adjusted IC（有限IC之和/应评估日数），明确不是标准IC。有效IC覆盖率低于90%不得靠删除无信号日过门槛。全零预测在收益筛查中持现金，绝不按股票代码买前几只。

开发候选由覆盖率≥90%的方法中最大coverage-adjusted mean IC确定，不能看后续指标替换。全部后续方法作为固定消融公开，但只有预封存候选用于主要财务门槛判断。

## 收益与准入

所有方法同一日历、H5周频调仓、前20%等权，10/20/30bp每边成本。两种事先固定政策：普通调仓、20%进入/40%退出缓冲。候选主要政策为缓冲，费用20bp。末尾清仓计费，缺报价按旧价估值并计数；仍是分数份额/后复权收益筛查，不是可执行现金股数账本。

后续财务门槛：IC覆盖≥90%、平均RankIC≥.02、至少75%半年折≥.02、20日区块1000次95%IC均值区间下界>0、候选净夏普严格>1。所有尝试计数公开；消融区间为描述性，不宣称研究历史全局多重检验通过。即便财务门槛通过，数据版本和真实成交结构未认证时也不自动启动模拟盘。
