# V9预注册：经济因子、逐期校准与持有期限

2020–2021开发，候选封存后计算2022–2024。所有历史已在先前研究使用，始终称回顾性评价。保留全部V1–V8报告。原58股和所有数据快照不变；不以减少费用、改变测试样本或挑选后段赢家达标。

## 待解决的问题

1. V8用3个月选模且按四块可靠性收缩，出现整折归零。恢复6个月有符号验证；加入不使用IC硬门控的对照。
2. EPS/BPS是每股金额，不是价格相对估值。新增披露/更新日+1可得的盈利收益率与账面价格比、已披露年度ROE、现金盈利比。EPS使用当前YTD+已知上年全年−已知上年同期的代理；缺任一分量保持缺失，不拿未来报表或简单年化补齐。每股口径遇股份变动仍未认证。
3. 加入12−1/6−1个月动量、60日低波动、126日市场beta等因子；同日截面排名只用当日及之前的数据。
4. 校准改用过去12个月逐期预测：2019开始每半年预测下一期，直到下一期标签退出后才能进入后续校准。每个模型参数来自它预测起点之前的完整6个月验证，所有边界H20 purge。

数据结构检查已发现年度ROE大面积缺失，部分年度UPDATE_DATE比最初公告晚约一年。坚持按较晚日期可得，不把修订值回填；加入报表年龄特征及修订滞后/缺失率审计。该诊断发生在任何V9模型拟合前，不能将缺失值处理说成恢复了原始历史版本。

## 固定五个模型

matched_control严格复现V7 long_history的30个月训练、6个月验证和可靠性；full_window相同数据/目标但取消可靠性硬归零；economic_h5修正经济因子与长期价量特征；economic_h20相同特征、全组H20训练目标；classic_value_quality为独立非学习基准。

四个学习模型名义信号权重仍为30/40/30。classic明确为50%价值质量+50%动量低波动，不伪称融合模型。其价值为盈利收益率/账面价格比等权，质量为年度ROE/负杠杆等权，二者等权成为基本面；价量为12−1动量、6−1动量、低波动等权。缺失字段在该基准内作中性值处理并公开覆盖。

Ridge alpha仍为[1,100,10000]、种子17；按平均有符号IC−0.5×四块均值标准差选择，不翻向。经济H20模型在H20上选模；全部模型主要评价仍是H5 IC。H20 IC和去市场均值H20收益R²另列，不能顶替H5门槛。

## 校准与三项固定组合政策

过去12个月的已成熟H20标签，逐日去均值后用`sum(score*excess_return)/sum(score²)`得斜率，负值归零、固定收缩0.5，不设任意斜率上限。用该斜率形成H20超额收益幅度；不引入V8的市场均值外推。超额收益预测不保证只多的绝对收益。

weekly_buffer每5交易日Top20%入、Top40%保留；slow_buffer相同规则但每20交易日；slow_net_edge每20交易日，以H20预期超额收益、H20风险协方差和成本约束求解现金/个股配置。协方差用过去60日收盘收益，样本与对角各半再乘20，风险厌恶5，单股≤10%、总仓≤100%。目标减当期换手单边费用和预留退出单边费用；路径只按实际模拟换手与末次清仓扣费。求解沿用V8近端算法、残差<1e-10，不复制参考项目代码。

独立等权基准equal_weekly、equal_slow、equal_slow_vol，分别5/20日调仓；后者目标年波动10%，不按α强度或未来开盘挑选股票，不作趋势择时。股票池可得性与所有模型相同。现金收益0、不做空或加杠杆。三种每边费用10/20/30bp，主费用20bp固定。

有效预测不足30只的缺预测日，统一保持原仓位，延续V7规则；有效但全平的选股信号才持现金，等权基准不按分数平坦程度停仓。首次开发核对发现实现误将缺预测当现金，导致对照路径偏离V7；已在封存/后段运行前修复并全量重跑。原尝试记录保留，不把规则修复算成新的α方法。

## 选优与评价

开发从15项模型/政策组合选一项：首先H5 IC≥0.02、至少75%半年折≥0.02、有效覆盖≥90%，然后要求平均仓位≥10%、至少100个非现金收益日，按20bp开发净夏普最高选。平局依配置顺序。无合格项则封存matched_control/weekly_buffer并标记选择失败；不能事后降低门槛。

后段同时保留所有消融，不能换冠军。主要门槛仍为上述H5稳定性、20日区块1000次bootstrap下界>0和封存方案净夏普>1。报告全成本路径、逐年、换手、暴露、最大回撤、等权对照、收益R²和条件区间。试验计数公开，不宣称完成整个历史的多重检验校正。
