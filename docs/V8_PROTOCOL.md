# V8：预期净收益、现金与风险接口

在拟合或查看本轮结果前冻结代码、配置与此协议并推送。V7所有报告保持原样。

固定58股、同一报价/新闻/财务快照、H5下一开盘至第六开盘目标、30/40/30信号权重、每边20bp主费用。10/30bp只做敏感性分析。使用2020–2021开发；封存唯一组合政策后运行2022–2024。历史区间以前已见，因此始终称回顾性评价，不声称新盲测。

## 预测与校准

每半年沿用30个月训练与6个月验证，但将验证分为前3个月选Ridge超参数、后3个月拟合收益幅度。选择期、校准期、评价期边界全部按真实H20标签退出日purge。校准期预测来自仅训练至校准期之前的模型；最后模型才使用评价开始前可得标签。保存两套checkpoint、各行预测和时间边界。

选模遵循V7的有符号稳定性，不通过绝对IC翻向。校准仅将融合分数映射到同日去均值H5收益：每日分数与收益均去均值，以样本协方差/方差得斜率，截到[0,0.1]再乘0.5。负关系归零，不能改成反向因子。校准期只拟合一个斜率；不尝试网格挑选。

报告基准预测的IC、区块区间与半年稳定率，以及收益预测R²、相对零预测的R²。R²按标准1-SSE/SST，不以IC平方替代。交易门控不会被解释成提升底层IC。

## 固定政策与公平对照

1. buffer：V7 Top20%入选、Top40%保留，全投资缓冲对照。
2. vol_buffer：同一名单，以60日协方差控制预期年波动10%，仓位不超过100%。
3. trend_vol_buffer：加等权股票池合成价格高于120日均线的趋势门控，其他时候现金。
4. net_edge：利用校准横截面预期收益及过去60日市场日均收益×H5×0.25作为市场分量，求成本与风险后的最优非负仓位。
5. trend_net_edge：同一配置器加趋势门控。

额外equal_trend_vol基准不参与选优：全池等权，使用相同趋势、目标波动与费用规则。现金基准收益为0。合成市场指标不是可交易指数，也不是独立大盘资料。

配置器最大单股10%、总仓位≤100%；H5协方差为过去60日收盘收益的样本协方差与其对角各半，乘5。最大化`mu*w - (5/2)*w'Cov_H5*w - 单边费用*|w-旧仓| - 单边费用*sum(w)`。末项为保守预留退出费，模拟时不预扣，而于真实调仓/终止时扣费。仅考虑当日已知收盘信息，不使用下一开盘决定是否下单。无有效预测/风险历史不足时持现金，禁止按未来停牌信息挑选赢家。

五交易日调仓，所有政策相同日历，终点统一清仓。费用沿用V7的比例复权收益研究筛查语义，保持完全相同；不是股数现金撮合账本。回撤、换手、平均暴露、现金比例、相对等风险基准结果均公开。

## 选优、评价与失败规则

开发阶段从五项政策按20bp净夏普选唯一候选，要求开发平均仓位≥10%、至少100个非现金收益日；平局按配置列表先后。全现金不能以零波动夏普冒充成功。若无合格政策，封存buffer并记录资格失败，不以降低门槛补救。

后段保留全部消融，但不能换冠军。主要财务门槛：共同底层信号平均IC≥0.02、至少75%半年折≥0.02、20日区块1000次bootstrap下界>0、有效IC覆盖≥90%，且封存政策20bp净夏普>1。报告相对等风险基准的配对收益区间，不能把择时盈利直接称为α。开发与后段不可合并来遮盖弱时期。

即使财务门槛通过，固定幸存者股票池、财务修订链缺失、新闻来源漂移及非可执行账本仍阻断模拟盘。订单0。不得以降低费用、筛选市场时期或重选后段赢家声称达标。
