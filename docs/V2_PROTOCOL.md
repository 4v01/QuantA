# QuantA V2 事前协议

本协议、代码和configs/v2.json在任何V2正式拟合前提交。冻结后，不按开发或确认测试表现改模型、候选、交易规则、时期或成本。V1报告、配置和实验记录不改。

## 假设及来源映射

| 来源 | 本项目可检验的迁移 | 边界 |
|---|---|---|
| [CogAlpha v4](https://arxiv.org/abs/2511.18850v4) | 分主题因子、有限模板变异/交叉、冗余及数值检查 | 自建12个初始因子，不运行其LLM或多代理系统，不复现论文数据/指标 |
| [XALPHA](https://arxiv.org/abs/2607.08332) | 研究线索→数据可行性→假设→实验→成功/失败记忆 | 保存结构化研究账本，当前候选不会读测试反馈再变异 |
| [MicroTSM预览](https://graceim.ai/zh/research/microtsm-financial-time-series-market-microstructure/) | 区分预测损失与交易效用 | 缺Level-2/逐笔数据，DROP，不以OHLCV假造订单簿 |
| [X开源算法固定提交](https://github.com/xai-org/x-algorithm/tree/3b6919f87532e57063bb3f1e85c2f509323b513e) | 候选来源、独立打分、多目标价值、过滤和相关性控制 | 不复制点击标签、社交图或大规模双塔；4只ETF全部召回，不声称召回算法增益 |

V1失败记忆形成两条约束：不得假定更大网络/记忆必然更好；成本与换手必须作为验证目标。以上仅为待验证设计，不承诺α。

## 数据、标签与分区

固定4只ETF、长仓、日频，所有旧限制沿用：现行第三方前复权、已知停牌保留估值、禁止停牌或10:30复牌日按9:30成交、连续名义权重及年度独立清仓。未解决逐时点复权、整手、最低佣金和开盘真实成交，不能声称工业级回测。

开发阶段只使用V1缓存2014–2024数据（SHA256在V1报告已公布）。2021–2024是设计已见过的探索性开发测试，**不是新的独立确认**。每个测试年Y，以Y-1作验证，更早历史训练。2025行情不得在开发前下载；冠军按4个开发折的验证净确定性等价收益均值选定，并提交公开封存文件后，才允许下载2025并运行确认。

输入为20个历史日的8项基础特征与12项可解释因子。全部方法共用因子最大120日历史导致的共同可用样本，不为基础模型放宽起点。信号在close[t]后生成，下一开盘open[t+1]执行。两个预测标签：

- 10日收益：mark_open[t+11]/mark_open[t+1]-1。
- 下行风险：上述10个开盘到开盘区间中负收益平方和的平方根。

训练及早停标签必须完整退出于下一分区之前，进入/退出开盘可交易，不能仅按信号日划分。最终重拟合只用完整标签退出日在测试年之前的训练＋验证数据。验证与测试组合日历保留全部日频持有区间；年度末没有完整10日预测标签的行仍产生预测并进入组合，只从10日预测误差计算排除。不缩短回测来获得更好结果。

价格相关矩阵使用信号close[t]时可见的最近60日收盘收益，向单位阵收缩10%；不是未来执行日或整个样本的相关矩阵。预处理、因子方向、尺度和选择只在对应拟合分区确定；最终拟合时可在训练＋验证上重新选择，不能读取测试。

## 有界自优化：12→24个候选，最多6个入模

初始因子为20/60/120日动量、5日反转、20日下行波动、60日回撤、量价相关、成交量相对偏离、20日区间压缩、趋势效率、K线压力和隔夜反转，覆盖6类机制。无会计/L2/社交特征。

每个候选仅在训练中计算分年度的pooled Spearman相关（不是论文中的逐日横截面IC）；根据训练总体方向定符号，稳定分=年度相关均值−0.5×年度相关标准差。选4个父因子，每个生成tanh归一化与波动门控两种变异，再生成4个父因子交叉，共24个候选。模板白名单不执行任意代码，不使用eval，也不调用付费LLM。

按稳定分排序，拒绝非有限/近常量、与已选候选绝对Pearson相关≥0.9者，最多选6个，保存全部拒绝理由和分数。重叠10日标签的相关统计只用于训练内筛选，不作为显著性证明。无测试引导的第二代或无限循环搜索。

## 模型、早停和预算

5个模型臂：基础Ridge、全部静态因子Ridge、演化选因子Ridge、演化因子双头HGB、演化因子双头LSTM。3个Ridge候选alpha=1/10/100；HGB两组叶数/正则、80轮、学习率.05、叶最小50、关闭隐藏随机验证早停；只用确定seed17。LSTM hidden16、两组学习率.001/.003、weight decay .001、最多20轮、batch256、梯度裁剪1、seed17/29/43。

LSTM每轮用验证联合原单位RMSE早停，patience3、min_delta1e-6，并恢复最佳轮参数。候选配置最终按统一主协议验证期**成本后确定性等价收益**选择：252×(日收益均值−0.5×3×日收益样本方差)。选中配置后重新初始化，训练＋验证拟合所选轮数。没有用验证期夏普无界优化。下行风险预测裁为非负，收益预测不裁剪。

共5年×(4个确定模型＋3个LSTM种子)=35个最终拟合；候选总数5×(3×3＋2＋2×3)=85。失败候选保留，不能静默补无限新配置；全部失败则停止。

## X式候选—价值—过滤映射与匹配消融

预测对每只证券独立，同一证券预测不受候选顺序/另一个候选是否出现影响；候选共用市场历史特征但不互看未来。组合候选固定为现金、4个单证券、6个两证券等权，另加当前漂移后持仓作为不换仓选项。

组合价值=预测10日收益−risk_penalty×预测组合下行风险−预估换仓及最终平仓费用。风险用预测下行风险和历史收缩相关矩阵构造，相关性低才有真实风险分散收益，而非把不同代码当独立资产。成本感知时固定用5bp估计，不随测试成本情景重新选参数。相等价值优先当前持仓。执行层独立阻断不可成交方向并保证费用后现金非负。

相同模型预测复用4种预声明消融：每日纯收益；每5个全市场交易日纯收益；每5日加风险惩罚0.1；每5日加风险惩罚0.1与成本（主协议）。年度第一天允许初始建仓，之后按原数据市场session模5，不能按哪个调仓日更好选择锚点。仍按日计算真实持有损益；10日预测不表示可以跳过中间亏损。

参照包括现金、沪深300和4ETF等权买入持有、逆波动组合、60日动量；后两者每5日调仓、以历史相关矩阵将年化波动目标定为10%，不使用测试选择风险目标。全部费用0/5/10/20bp、终端平仓费用、T+1与停牌处理相同。

## 确认、审计与交付

冠军模型类别只按4个开发折的验证净效用跨种子均值选择；配置与全部种子固定。神经冠军2025决策使用3个种子预测均值，其他类别确定性。2025超参数可以按2024验证选择，标签不跨入2025；所有方法均在2025重拟合并全量报告，不能换成2025最高收益模型。

主要确认规则：预封存冠军2025净夏普为正，且相对沪深300和逆波动两项年化算术平均超额收益的配对20日循环区块bootstrap（1000次）97.5%区间下界都大于0。两项比较用Bonferroni控制家族95%覆盖；未达到即未通过，不能改阈值。HAC CAPM α、逐年表现、RankIC及其他消融为辅助描述，不可替代主要确认规则。
