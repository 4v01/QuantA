# V4 固定协议：先信号，再非线性与增量，最后模拟准入

本轮按用户指示使用AKShare。60只长期上市股票代码先写入configs/v4.json再训练，没有根据本轮收益替换股票。样本是人工固定存续样本，不代表历史全A股，也不是历史沪深300成分。数据区间2014-01-01至2026-10-30；截止日沿用V3，不因结果更改。2021–2026全部是回顾性开发。

1. **数据与基础因子**：同一个AKShare东方财富stock_zh_a_hist接口，原始OHLCV与hfq两套不可覆盖CSV，逐文件SHA256、取数时刻、库版本。拒绝不完整股票池/无声换源。保留完整交易日并集，缺失因子不向前填充，排除行计数。27个无量纲价量因子，同日截面秩；不放入后复权绝对价格/未来财务或历史新闻。
2. **标签与滚动**：H=5，close t决策，t+1开盘到t+6开盘hfq收益代理。每半年测试，之前30个月训练+6个月验证。训练标签退出日严格小于验证开始；最终重拟合用过去36个月且标签退出日严格小于测试开始。样本外最后6个无标签日不用于IC，但有信号的日期仍参与收益筛查。半年测试不等于半年持仓。
3. **线性检验**：Ridge α=[1,100,10000]；ElasticNet α=[.001,.01,.1]、l1_ratio=.5。只看验证日均Spearman IC选择参数和方向；最终在测试前重拟合。标准化训练拟合，非全样本。主信号门槛：有向样本外平均RankIC≥.02，≥75%半年折达到.02，循环20日区块1000次95%区间下界>0。绝不平均逐日|IC|，每折正负方向不得事后改。最低截面30只。
4. **非线性/增量**：LightGBM leaves=[15,31]，最多300轮、验证早停30轮，其余固定；先早停/验证选择再按选定轮数重拟合。gplearn选择轻量符号因子扩展，而非本轮同时扩大到Transformer：每折人口128×4代，最多6000训练样本、4个新特征、复杂度惩罚.01；公式只在训练生成，验证选Ridge α/方向，公式不在测试重挖。比较同日配对ΔRankIC与区块区间。
5. **辅助X机制**：参考官方Home Mixer的候选→特征→评分→过滤架构；以相同LightGBM预测秩减.2波动秩加.1流动性代理秩，再在验证定方向。权重是本项目冻结假设，不是X原始金融算法。没有假装掌握用户互动图或X模型权重。独立实现，不复制AGPL源代码。
6. **连续OOF收益筛查**：5交易日调仓、前20%等权、不做空不杠杆，跨年不重置。相同可预测样本的全池等权为参照。成本每边10/20/30bp，20bp为主，末尾清仓也计费。不根据曲线选择场景。此分数份额/后复权因子组合没有历史税率、分红现金/整手/涨跌停成交账本，不能作为可执行回测或模拟成交保证。
7. **准入**：验证IC均值选择候选而非OOF夏普择优。线性门槛通过+候选信号门槛通过+主情景OOF净夏普严格>1+各评估年净收益>0+历史可得股票池/事件认证+可执行账本，才可申请进入未来本地纸面评估。本轮公共数据不满足最后两项，即使点估计亮眼也不能跳过。高级臂在线性失败时仅做探索诊断。
8. **舆情**：AKShare新闻采集保存发布和首次观察两个时间，决策可得时刻取两者最大值。当前新闻不能回填到历史首次可见状态。无可信旧档案，历史模型不加舆情，词典计数仅用于后续前向验证。

正式训练要求源工作树clean，保存提交/config/data manifest/每个checkpoint/prediction哈希及seed17、环境版本。候选数公开。新试验不得覆盖旧报告；不把这一轮2026再称新盲测。公开IC区间是描述性诊断，不是研究历史的全局多重检验校正。

## 原始参考与取舍

- [AKShare官方股票数据文档](https://akshare.akfamily.xyz/data/stock/stock.html)：接口和字段随版本变化，运行固定1.20.37并验证实际返回。
- [LightGBM官方参数](https://lightgbm.readthedocs.io/en/stable/Parameters.html)：CPU确定性、固定seed、force_col_wise；早停仅看验证。
- [gplearn SymbolicTransformer](https://gplearn.readthedocs.io/en/stable/reference.html#symbolictransformer)：以训练目标挖相关公式再作为下游线性特征；不把公式训练适应度当OOF增量。
- [X / Twitter官方Home Mixer](https://github.com/twitter/the-algorithm/blob/main/home-mixer/README.md)：借鉴分阶段结构；证券未来收益不是用户点击偏好，不能把推荐提升推断为交易α。
- [微软Qlib](https://github.com/microsoft/qlib)：价量因子→滚动预测→组合评估的可比较流程参考，未声称复现Alpha158完整集合、其数据或论文成绩。

上述是代码/方法来源，不把外部市场或协议的成绩当本项目benchmark。更复杂模型不保证强于线性。
