# 冻结预测的五组错峰实验：计算结果前固定

本轮只改变持仓时钟，不拟合模型、不改变30/40/30融合、不替换V9预测或财务输入。2020–2021与2022–2024均为已见历史，始终称回顾性研究。代码、参数和输入哈希在任何本轮结果计算前公开推送。

## 唯一主方案及全部对照

唯一主方案预先固定为economic_h5/stagger5，对照为同预测phase0。matched_control是第二个固定预测对照；equal_weight为不依赖α强弱的基准。每种预测/基准均计算phase0至phase4和stagger5，全部公开；五个单相位只诊断，不按开发或后段选择最佳相位、预测模型或费用。

所有方案从相同第一交易日现金开始，按此前收盘信号在下一开盘部署。phasek从第k个交易会话开始，每5会话调仓。stagger5分成初始各20%资金的五个虚拟组，第j日只调第j mod 5组；各组起初现金，前五日逐组部署。主比较包含启动期。预设次比较从第5会话后开始，不能以次比较替代主结果。

名单仍为Top20%进入、Top40%缓冲保留，沿用V7排序/缺预测保持原仓位/全平选股现金规则；等权基准不按α平坦度停仓。不得用未来开盘或未来停牌标志决定下单。日历、58股与标签保持V9原样。

## 资金、净额与费用

每组只使用自己的资金，不每天强制重置成全基金20%。组预算随其持仓盈亏漂移，组现金保留；不存在外部注资或用未持有的资金买入。五组的实际目标权重合并后，按总目标与基金当前总持仓之差计外部权重换手。不得简单平均五条净值或五个夏普来代替合并账户。

费用延续V9的比例份额研究筛查：在当日收益前按基金资金同比例承担，末尾统一清仓；同一虚拟持仓路径分别按每边10/20/30bp重算净收益，20bp是唯一主费用。费用不改变各组相对资金预算，故持仓证据不按费用重复。该约定保证phase0可重现V9；它不是逐股现金、手数、T+1或真实开盘撮合账本。

设组持仓为S、预算为b，收益向量r：基金毛收益g=sum(S*r)，下一日S'=S*(1+r)/(1+g)，b'=(b+S*r)/(1+g)。比例费用由全基金共同承担，不产生组间资金转移。逐日保存组预算、现金、组持仓和基金合计，独立核验预算和收益守恒。

同时报告各组意图绝对值总和与净外部换手。正常每天仅一组调仓，跨组相反交易未必存在；不得把时钟改善或名单重合误称为净额节费。

## 固定指标与判定

H5 IC直接继承冻结预测，时钟不能提升模型IC。报告净夏普、累计收益、回撤、换手、暴露、费用、启动期次比较、逐年结果及相对phase0/等权的配对20会话区块区间（1000次，种子17）。全部单相位均展示，但不设相位赢家。零费仅同持仓归因。

唯一主方案在后段仍需原H5有符号IC≥0.02、至少75%半年折达标、有效覆盖≥90%、区块区间下界>0，以及每边20bp净夏普>1。即使满足数值门槛，仍是旧历史回顾性检查，不解除历史修订、固定幸存者样本和非可执行账本阻断。模拟盘不启动，订单0。

原始公告核验单独推进，保存原文/公告元数据/实际first_seen；不得混入本轮冻结预测。正式的新数据训练与前瞻窗口仍须单独完成数据验收和公开协议。
