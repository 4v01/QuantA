# 根据首次融合IC选择的改进：新闻实体与文本编码

选择发生在2020首轮完成后、2021随访正式拟合前；机器可读计划configs/v6_improvement.json记录首轮源提交及ic_summary SHA256。计划随首轮结果一起公开推送后才拟合随访。

## 证据与推断

首轮：融合IC0.003686，价量0.006823，新闻-0.004293，基本面-0.002642；所有均值区间跨0。新闻与价量预测相关约0.007，故目前更像低效/嘈杂的新信息，而非已证实的重复信号。基本面两个半年反向，价量自身也弱；不能认定仅修新闻就能解决整个策略。

核对原始公司新闻表发现其它公司主题条目；现有15项条数/词典/长度只能表达粗糙情绪。以“先确认标题实体，再学习字符语义”为一个改善方向，保留失败可能。

## 一次封存的三个随访臂

1. baseline：原始新闻集合+原15项统计。
2. entity_filter：仅完整归档公司名的精确匹配，仍为15项统计；不在看随访收益后手加别名。它是实体关联这一组件的消融。
3. entity_tfidf：相同实体过滤，追加最近5日历天已可得标题的字符2–3gram TF-IDF，max_features4096/min_df5、最多8000字符，训练期词表；Ridge稀疏lsqr/tol1e-5。仍只有原alpha三候选、过去验证定方向。

日期、58股共同样本、H5、组权重、费用和价格/基本面编码不改。全部臂在2021同日期对比组IC、融合IC/IR、配对区间和收益筛查。不根据2021结果再选配置覆盖“原定方案”，也不把表现最高的一臂称盲选冠军。

文本最终重拟合仅用该折以前资料；测试新词不会进入拟合词表。权重30/40/30保持固定；若新闻仍弱，也不会把这30%偷偷交给价量。数据历史可得性仍未认证，2021是回顾性复核，旧V5模拟门槛不变。
